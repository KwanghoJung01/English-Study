# 매일 영어 스피킹

수준과 주제를 고르면 지문이 자동으로 생성되고, **독해 → 단어학습 → 스피킹 연습(듣기·녹음·피드백)**까지 하루 한 번 학습하는 안드로이드용 웹앱(PWA)입니다. 서버 없이 정적 웹으로 동작하며, GitHub Pages에서 무료로 호스팅하고 진행 기록은 이 저장소에 자동으로 커밋되어 여러 폰에서 동기화됩니다.

## 주요 기능

- **지문 자동 생성**: Gemini 2.5 Flash(무료 API, 사용자 키 입력)로 매번 새 지문을 생성하거나, 키가 없어도 내장된 콘텐츠 뱅크(입문/초급/중급/고급 × 주제)로 바로 학습할 수 있습니다. Gemini 생성이 실패하면 자동으로 콘텐츠 뱅크로 대체됩니다. **입문** 레벨은 초등 1~3학년 눈높이의 아주 짧고 쉬운 문장(그림책 수준)이며, 선택 시 아이에게 맞는 주제(일상생활/여행/동물/학교생활/취미/음식)만 보여줍니다.
- **독해**: 생성된 지문 + 핵심 어휘 하이라이트 + 객관식 이해도 문제. 지문이 나오자마자 원어민이 전체 읽어주는 기능으로 먼저 듣고 따라 읽을 수 있고, **재생/일시정지/정지** 버튼으로 언제든 멈췄다 이어들을 수 있습니다(일시정지 후에는 멈춘 문장부터 이어듣기, 정지 후에는 처음 문장부터 다시 시작). 지금 읽어주는 문장은 배경색으로 강조돼요. 문장마다 **"해석 보기"** 버튼으로 바로 아래에 한국어 해석을 켜고 끌 수 있어 뜻을 몰라도 바로 확인할 수 있습니다(**입문** 레벨은 기본으로 켜져 있고, 그 외 레벨은 스스로 먼저 읽어보도록 기본은 꺼져 있어요).
- **단어학습**: 지문에서 뽑은 핵심 단어 플래시카드. 뜻을 확인하면 자연스러운 유의어·반대말이 있는 단어는 함께 표시됩니다(모든 단어에 있는 건 아니에요 — 억지로 짝을 만들지 않습니다). 학습한 단어는 개인 단어장에 쌓이고, 진행 기록 탭에서 간격 반복(SRS) 방식으로 복습할 수 있습니다.
- **스피킹 연습**: 문장마다 (1) 원어민 음성으로 듣기(속도 조절), (2) 내 목소리 녹음 및 인식, (3) 목표 문장과 비교한 단어별 정확도 하이라이트 + 말하기 속도(WPM) 피드백을 제공합니다. 독해와 마찬가지로 문장마다 **"해석 보기"**로 한국어 해석을 켜고 끌 수 있습니다. 모든 문장 연습이 끝나면 **전체 지문을 한 번에 듣고 → 한 번에 읽어 녹음**하는 마무리 단계로 이어지며, 전체 듣기에도 재생/일시정지/정지 버튼, 지금 읽는 문장 강조, 해석 보기가 똑같이 적용됩니다. 전체 읽기 시간·WPM과 함께 문장별 발음 정확도를 자동으로 나눠 보여줍니다.
- **하루 1회 학습**: 오늘 학습을 완료하면 홈 화면에 완료 표시가 뜨고, 추가로는 스트릭에 영향 없는 "복습 모드"로만 다시 연습할 수 있습니다. 홈 화면에서 연속 학습일(스트릭)과 함께 지금까지 학습한 총 일수도 확인할 수 있어요.
- **가족 프로필**: 화면 상단에서 가족 구성원 프로필(이름/아이콘/색상/기본 수준)을 전환하며 각자 따로 학습하고 기록을 관리할 수 있습니다. **가족 비교** 탭에서 스트릭·정확도·단어장을 한눈에 비교할 수 있어요.
- **진행 기록 동기화**: 각 프로필의 스트릭, 세션 기록, 단어장을 IndexedDB(기기 로컬)에 저장하고, GitHub Personal Access Token을 등록하면 `progress/state.json`으로 이 저장소에 자동 커밋되어 어떤 폰에서 열어도 같은 기록을 볼 수 있습니다. 가족이 서로 다른 기기를 쓰더라도 프로필 단위로 병합되어 서로의 기록을 덮어쓰지 않습니다.
- **PWA**: 안드로이드 Chrome에서 "홈 화면에 추가"로 설치하면 네이티브 앱처럼 사용할 수 있고, 콘텐츠 뱅크 기반 학습은 오프라인에서도 동작합니다.
- **듣기 속도 조절**: 독해·단어학습·스피킹 등 원어민 음성이 나오는 모든 화면에 느리게/보통/빠르게 속도 버튼이 있어 어디서든 바로 바꿀 수 있고, 그 즉시 해당 프로필에 저장됩니다.

## 처음 설정하는 방법

### 1) GitHub Pages 배포 활성화 (최초 1회, 저장소 관리자만 가능)

1. GitHub 저장소 → **Settings → Pages**로 이동합니다.
2. **Build and deployment → Source**를 **GitHub Actions**로 설정합니다.
3. `main` 브랜치(또는 이 브랜치)에 푸시하면 `.github/workflows/deploy.yml`이 자동으로 빌드/배포합니다. 완료 후 `https://<계정>.github.io/English-Study/` 주소로 접속할 수 있습니다.

### 2) (선택) Gemini API 키 발급 — 매번 새로운 지문을 받고 싶다면

1. https://aistudio.google.com 에서 Google 계정으로 로그인합니다.
2. **Get API key**로 무료 API 키를 발급받습니다 (`gemini-2.5-flash` 무료 티어 사용).
3. 앱의 **설정 → Gemini API 키**에 입력합니다. 키는 이 기기의 브라우저에만 저장되고 코드/커밋에는 절대 포함되지 않습니다.
4. 키를 등록하지 않아도 내장 콘텐츠 뱅크로 바로 학습할 수 있습니다.

### 3) (선택) GitHub 진행 기록 동기화 — 여러 폰에서 같은 기록을 보고 싶다면

1. GitHub → 우측 상단 프로필 → **Settings → Developer settings → Personal access tokens → Fine-grained tokens**로 이동합니다.
2. **Repository access**를 이 저장소 하나로 제한하고, **Permissions → Contents: Read and write**만 부여합니다. (그 외 권한은 주지 않는 것을 권장합니다.)
3. 발급된 토큰을 앱의 **설정 → GitHub 진행 기록 동기화**에 저장소 소유자/이름/브랜치와 함께 입력하고 "GitHub 자동 동기화 사용"을 켭니다.
4. 이후 학습을 완료할 때마다 `progress/state.json`이 이 저장소에 자동 커밋됩니다. 다른 폰에서 같은 토큰(또는 각자 발급한 토큰)을 등록하면 최신 기록을 불러와 병합합니다.
5. 토큰은 브라우저 로컬 저장소에만 보관되며, 공유 기기에서는 사용 후 삭제하는 것을 권장합니다.

### 4) 안드로이드 폰에 설치하기

1. Android Chrome에서 배포된 주소로 접속합니다.
2. 우측 상단 메뉴(⋮) → **홈 화면에 추가**를 누릅니다.
3. 홈 화면 아이콘으로 실행하면 주소창 없이 네이티브 앱처럼 사용할 수 있습니다.

### 5) 가족과 함께 쓰기

1. 처음 접속하면 프로필 만들기 화면이 뜹니다. 이름/별명, 아이콘, 색상, 기본 수준을 정해 첫 프로필을 만드세요.
2. **설정 → 가족 프로필**에서 "+ 새 프로필 추가"로 다른 가족 구성원을 추가할 수 있습니다(인원 제한 없음).
3. 화면 상단의 프로필 칩을 눌러 학습할 사람을 전환합니다. 현재 선택된 사람은 진하게 표시되고, 학습 화면 우측 상단에도 항상 표시됩니다.
4. 각 프로필은 독립적인 스트릭·학습 기록·단어장을 가지며, 하루 1회 학습 제한도 프로필별로 따로 적용됩니다.
5. **가족 비교** 탭에서 모든 프로필의 스트릭/정확도/단어장을 한 화면에서 비교하고, 바로 다른 사람으로 전환할 수 있습니다.
6. 개인정보 보호를 위해 이름은 실명보다 별명을 권장합니다. 진행 기록 저장소를 비공개로 유지하면 더 안전합니다.

## 로컬 개발

```bash
npm install
npm run dev       # 개발 서버
npm run build     # 타입체크 + 프로덕션 빌드 (dist/)
npm run preview   # 빌드 결과 미리보기
```

## 알아두면 좋은 점 (제약사항)

- 스피킹 피드백은 브라우저 내장 음성 인식(Web Speech API)의 전사 결과를 목표 문장과 비교하는 방식입니다. 실제 음성학적 발음 분석(억양, 강세 등)이 아닌 **인식된 단어의 정확도 기반 근사치**입니다.
- 음성 인식/합성은 Android Chrome 등 Web Speech API를 지원하는 브라우저에서 가장 잘 동작합니다. 데스크톱 헤드리스 환경이나 일부 브라우저에서는 지원되지 않을 수 있습니다.
- 녹음한 오디오는 세션 화면에서만 재생되며 GitHub에는 업로드되지 않습니다(전사 텍스트와 점수만 동기화됩니다).
- 콘텐츠 뱅크는 레벨×주제 조합당 1편씩 내장되어 있습니다. `src/data/bankPassages.ts`에 항목을 추가해 더 다양하게 확장할 수 있습니다.
- 가족 프로필 기능 이전에 이미 학습 기록이 있었다면, 처음 접속 시 자동으로 "나"라는 프로필로 옮겨져 데이터가 유지됩니다.
